# Claude 接班说明：Serenity 投资帖视频制作

## 任务

用户发送一组 X 帖截图后，将每一条独立帖子制作成一套中文 B 站视频素材：

1. 一个视频标题，放在单独的 `plain text` 代码块。
2. 一篇中文配音稿，放在另一个 `plain text` 代码块。
3. 一张 1273×716 封面图，将封面标题直接写进图里。
4. 原帖截图拼图，1273×716，每页放 2–3 张完整截图。截图过多就分多页。

请交付实际图片文件，不能只描述制图方案。用户传来的多张图片可能是一条长帖，也可能是几条独立帖子；先按账号、内容连续性、引用框和最末尾的发布时间/互动栏判断分组。若还有截图待发，先收齐该帖再制作。

## 当前输出规则，以此为准

- **每篇只选一个视频标题**。不要给三选一。标题通俗，尽量避免生僻缩写；风格可以有变化，不要连续使用问句。
- **封面标题只出现在封面图片内**，文字回复中不要另列“封面标题”。
- **不提供关键词**，也不使用“写作框架”之类的栏目。
- 配音稿开头必须写截图中的**准确发布时间，精确到分钟，24 小时制**，格式如：`2026年10月17日，06点25分。`。不要只写日期，也不要把手机状态栏时间误作发帖时间。若截图看不到发布时间，要继续查原帖；仍查不到则标明无法确认，不能编造。
- 稿件适合口播，按语意换行，通常每行约 15–25 个汉字；长帖可写充分一些，不要为了简短漏掉重要事实和逻辑。
- 不写“欢迎关注”“如果你想继续追踪”等对观众的额外话，不写泛泛的免责声明，不使用机械化的总结模板。
- 事实、渠道调查、预测、作者推断须分别归属；订单、认股权、意向协议、已签合同不能混同。重要数字核对来源，尤其是股价、财报、产能、日期和单位。不能查证的具体推测应明确标注。
- 用户明确要求避免“不是……而是……”句式。

## 封面图

参考用户惯用模板 `references/封面模板_1273x716.png`：纯黑底、左侧 Serenity 白发圆形头像，右侧三行依次为 `Serenity`、`最新帖子解读`、`YYYYMMDD HH:MM`，下方一行简短中文封面标题。整体留白和字重参照原图。尺寸必须为 **1273×716**。封面内容按当前帖子替换，发布时间仍用原帖时间。检查中文字、日期和冒号准确，不能出现乱码或生成错字。

## 原帖拼图

参考样张 `references/原帖拼图参考.png` 和最新修正版 `references/原帖拼图_修正版_1273x716.png`。纯黑背景；每页 2–3 张截图，**相邻截图靠近，中间只留很小的缝**，整体居中。不要把两张图分别推到左右边缘，造成巨大的中间空白。

保留用户原图的全部内容，特别是最后一张底部的**发帖时间、查看次数、回复、转帖、喜欢、收藏**。不要裁掉顶部账号、嵌入的引用帖或底部互动栏。截图底部到画布底边留约 150–200 像素黑色区域供用户写字幕。图片缩放可能降低可读性，必要时每页放 2 张或分更多页，优先保证文字可辨。交付前实际打开成品检查。

## 一次新任务的执行顺序

1. 收齐、查看上传图片，按原帖分组；从底部互动栏记录确切年月日、时分及数字。
2. 查证时效性和金融相关事实；区分原帖观点与公司正式披露。
3. 写每篇唯一的视频标题与配音稿，放在两个独立的 `plain text` 代码块。
4. 按模板制作每篇 1273×716 封面，标题直接入图。
5. 把该篇的原帖截图完整拼图，2–3 张/页，靠拢排列，保留完整互动栏，底部留字幕区。
6. 检查封面文字、时间、拼图边界和分组；交付可下载的封面及拼图文件。
