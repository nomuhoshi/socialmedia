# Serenity 社交媒体内容制作

这个仓库保存 Serenity 投资帖转 B 站视频素材的制作规范和参考图。

## Claude 使用方式

1. 先读取根目录的 `CLAUDE.md`。
2. 用户每次提交一批原帖截图后，按照其中的分组、查证、写稿和制图流程执行。
3. 参考 `references` 文件夹中的封面和原帖拼图样张。

## 文件说明

- `CLAUDE.md`：完整接班说明和固定制作规则。
- `references/封面模板_1273x716.png`：常用封面版式。
- `references/原帖拼图参考.png`：原始拼图参考。
- `references/原帖拼图_修正版_1273x716.png`：缩小截图间距并保留底部字幕区的最新版样张。

## 当前核心要求

- 每篇只输出一个最佳视频标题。
- 封面标题直接写入图片，不在文字回复中重复。
- 不输出关键词。
- 配音稿首行写准确发布时间，精确到分钟，使用 24 小时制。
- 每页放 2–3 张原帖截图，保留发布时间、查看次数、回复、转帖、喜欢和收藏。
- 相邻截图靠近排列，画面底部保留字幕区域。
